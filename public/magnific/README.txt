Swapping in Freepik / Magnific images:
  Download your chosen images and save them here with the SAME filenames above
  (overwrite). No code change needed — the page picks them up automatically.
  Recommended: warm-toned salon/spa photos that sit well with the olive+cream+gold
  palette. Landscape ~1200px wide for hero/mobile; portrait ~800px tall for the
  deep-dive collage photos (styling/makeup/facial).
